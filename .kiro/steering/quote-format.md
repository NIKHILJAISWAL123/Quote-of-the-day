# Quote Format & Data Standards

This document specifies the exact format and validation rules for quotes.

## Quote Data Model

```typescript
interface IQuote {
  id: string;                    // UUID v4 format
  text: string;                  // Main quote text
  author: string;                // Attribution
  category: QuoteCategory;       // Predefined category
  dateAdded: string;             // ISO 8601 timestamp
  source?: string;               // Optional: book, speech, URL
  isAIGenerated?: boolean;       // Flag for machine-generated quotes
  explanation?: string;          // AI-provided meaning/context
}

type QuoteCategory = 
  | 'motivation' 
  | 'success' 
  | 'funny' 
  | 'wisdom' 
  | 'leadership' 
  | 'other';
```

## Validation Rules

### Text Field
- **Required:** Yes
- **Type:** String
- **Min length:** 10 characters
- **Max length:** 500 characters
- **Must not:** Contain only whitespace
- **Must not:** Start/end with quotes or special characters (except punctuation)

### Author Field
- **Required:** Yes
- **Type:** String
- **Min length:** 2 characters
- **Max length:** 100 characters
- **Format:** "FirstName LastName" or "Organization Name"
- **Cannot be:** "Unknown" or "Anonymous" (use "Unknown Author" instead)

### Category Field
- **Required:** Yes
- **Type:** Enum (one of 6 predefined values)
- **Valid values:** `motivation`, `success`, `funny`, `wisdom`, `leadership`, `other`
- **Case-sensitive:** lowercase only

### ID Field
- **Required:** Yes
- **Type:** UUID v4 string
- **Format:** `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`
- **Unique:** Must not duplicate existing IDs
- **Auto-generated:** System generates, not user-provided

### Date Added Field
- **Required:** Yes
- **Type:** ISO 8601 timestamp
- **Format:** `YYYY-MM-DDTHH:mm:ss.sssZ`
- **Auto-populated:** Set to current time when quote created
- **Cannot be:** Future date

### Source Field
- **Required:** No
- **Type:** String (when provided)
- **Max length:** 200 characters
- **Examples:** "Steve Jobs Stanford Commencement 2005", "The Power of Now - Eckhart Tolle"

### Explanation Field
- **Required:** No (optional for AI-generated quotes)
- **Type:** String
- **Max length:** 300 characters
- **Purpose:** AI-provided context or meaning

### isAIGenerated Flag
- **Required:** No (defaults to false)
- **Type:** Boolean
- **Usage:** Marks quotes generated by AI service
- **Affects:** May display AI disclaimer with quote

## Category Guidelines

### Motivation
- Inspirational messages
- Overcoming obstacles
- Personal growth
- **Example:** "The only way to do great work is to love what you do."

### Success
- Achievement and goals
- Hard work and dedication
- Winning mindset
- **Example:** "Success is not final, failure is not fatal."

### Funny
- Humorous quotes
- Witty observations
- Lighthearted wisdom
- **Example:** "I told my computer I needed a break, and now it won't stop sending me Kit-Kat ads."

### Wisdom
- Ancient wisdom
- Life lessons
- Philosophical insights
- **Example:** "The only constant in life is change."

### Leadership
- Management philosophy
- Team dynamics
- Decision making
- **Example:** "A leader is one who knows the way, goes the way, and shows the way."

### Other
- Quotes that don't fit categories
- Miscellaneous
- Experimental quotes

## Validation Examples

### ✅ Valid Quote
```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "text": "The only way to do great work is to love what you do.",
  "author": "Steve Jobs",
  "category": "motivation",
  "dateAdded": "2026-09-29T10:30:00.000Z"
}
```

### ❌ Invalid Quote (Text too short)
```json
{
  "text": "Success",  // ❌ Less than 10 characters
  "author": "Unknown Author",
  "category": "success"
}
```

### ❌ Invalid Quote (Bad category)
```json
{
  "text": "Great quote here",
  "author": "Someone",
  "category": "MOTIVATION"  // ❌ Must be lowercase
}
```

### ❌ Invalid Quote (Author too short)
```json
{
  "text": "Great quote here",
  "author": "A",  // ❌ Less than 2 characters
  "category": "other"
}
```

## Import Standards

When importing quotes from external sources:
1. Validate against all rules above
2. Map source category to one of 6 categories
3. Clean whitespace and normalize text
4. Verify author attribution accuracy
5. Add source metadata if available

## Property-Based Invariants

These properties must ALWAYS hold:
1. Every quote has a valid UUID
2. Text length always between 10-500 characters
3. Author length always between 2-100 characters
4. Category always one of the 6 valid types
5. dateAdded is never in the future
6. IDs are always unique in the collection
7. Quotes never have null/undefined text or author
